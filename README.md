# Game Boy Indie Devlog

My trials and tribulations into gameboy game design and a deeper understanding of c and limitied harware capabilities. 

## Toolchain & Reasources 
* **Compiler:** [GBDK-2020](https://github.com/gbdk-2020/gbdk-2020.git)
* **Emulator:** [BGB](https://bgb.bircd.org/)
* **Art & Audio Tools** [GBTD](https://www.devrs.com/gb/hmgd/gbtd.html), [GBMB](https://www.devrs.com/gb/hmgd/gbmb.html)
* **Tutorials:** [GamingMonsters](https://www.youtube.com/@GamingMonsters)

## Repository Structure
* `tutorials/` — Practice exercises and hardware experiments
* `games/` — Original indie game prototypes
* `notes/` — Register cheat sheets, tile math, and dev logs
